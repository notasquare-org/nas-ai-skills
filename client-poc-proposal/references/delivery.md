# Driveへの納品

## 入れるもの

「見せるものだけ」。基本は紹介動画の2本。コード、作業用の文書、素材、ログは入れない。FEASIBILITY.md などの文書を入れるのは、ユーザーに頼まれたときだけ（PDFにして入れる）。

## 手順

1. 入れる先のフォルダ（URL）をユーザーに聞く。案件ごとに違う。共有ドライブの、社内メンバーだけが見られるフォルダのことが多い。
2. フォルダの中身を一覧して、同じ名前・同じ中身のファイルがないか確かめる。二重に入れない（以前、同じ動画を名前違いで2つ入れてしまったことがある）。
3. 1ファイル10MBを超えるものは縮める（Driveコネクタのアップロード上限）。
   ```sh
   sh <このスキル>/scripts/shrink_for_drive.sh <動画.mp4>   # → <動画>-drive.mp4
   ```
   画質の設定（CRF）を24から順に上げ、上限に収まった所で止める。CRF 24 で、見た目をほぼ変えずに4MB台になった例がある。
4. 名前を付けて入れる。
   - 声・BGM付き: 「〈先方名〉様_〈内容〉（声・BGM付き・約N分）.mp4」
   - 音なし: 「〈先方名〉様_〈内容〉（音なし・約N分）.mp4」
   - 案件フォルダの元のファイル名は変えなくてよい。Drive に入れるときの名前だけ整える。
5. 作り直した版は差し替える。Drive のコネクタでは中身を上書きできない。そのため、新しい版を入れてから古い版をゴミ箱に移す。古い版を移すかは、先にユーザーに聞く（ゴミ箱からは戻せる）。
6. 入れたファイルの名前とリンクを報告する。

## コネクタでの入れ方

- アップロードは create_file に、ファイルの参照（`sha256:<ハッシュ>:<絶対パス>`）を渡す。ハッシュは `shasum -a 256 <ファイル> | cut -c1-64` で出す。
- `contentMimeType` は `video/mp4`。Google形式に変換させない設定（`disableConversionToGoogleType: true`）にする。
